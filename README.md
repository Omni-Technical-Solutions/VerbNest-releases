# VerbNest

Local-first API client: send HTTP requests, keep everything on your device.

This repository hosts the VerbNest installers. Download the latest one from [Releases](https://github.com/Omni-Technical-Solutions/VerbNest-releases/releases).

## Windows

Install with winget (once the package is published):

```powershell
winget install Omni.VerbNest
```

Or download `VerbNest-<version>+<build>-windows-x64-setup.exe` from the latest release and run it. It installs for the current user without admin rights. The installer is not code-signed yet, so Windows SmartScreen may show a warning: choose "More info", then "Run anyway".
